# Shelter Optimization Framework

This repository contains the code for:  
**"A proximity‑based multi‑indicator framework for optimizing emergency shelter layout in a mountainous city: A case study of Dujiangyan, China"**

## Repository Structure

| File |
|---|
|  Main greedy optimization and result export |
|  EWM weight calculation for four hazard types |
|  Combined suitability assessment |
|  Weight distribution visualization |
|  RF importance comparison |
|  Sensitivity analysis of α combination |
|  Objective weight sensitivity analysis |
|  Sensitivity visualization |
|  Algorithm comparison |
|  Hazard-specific shelter selection |
|  Existing shelter suitability evaluation |
